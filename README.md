# 多模型协同工作流框架（Multi-Model Orchestration Framework）

## 项目概述

这是一个基于Claude Skills标准的多模型工作流执行框架实验项目。目标是验证**不同AI模型（Gemini、Claude、其他）能否在同一工作流中协同工作**，通过指定模型执行不同的任务步骤。

## 核心思想

在复杂的AI任务中，不同的模型擅长不同的领域：
- **Claude** 擅长代码生成和逻辑推理
- **Gemini** 擅长多模态理解和实时信息获取  
- **其他模型** 各有专长

通过一个统一的工作流框架，让每个模型在其擅长的领域发挥最大效能，而不是让一个模型处理全部任务。

## 项目结构

```
two-sklls/
├── .claude/
│   └── skills/
│       ├── main-process/       # 主流程技能（工作流编排）
│       ├── drawing/            # 绘图技能（子技能示例）
│       └── skill-creator/      # 技能创建指南
└── README.md                   # 本文件
```

## 关键特性

- ✅ **Skill间互相调用** - 验证main-process能否委派给drawing等子技能
- ✅ **模型指定执行** - 在skill定义中指定使用的模型
- ✅ **标准框架** - 遵循Claude官方Skill实现标准
- 🔄 **可扩展性** - 支持添加更多模型和技能

## 使用方式

### 执行主流程

```bash
# 触发main-process技能，自动委派给drawing技能
执行技能main-process
```

### 创建新技能

参考 `.claude/skills/skill-creator/SKILL.md` 了解如何创建符合标准的新技能。

## 实验阶段

当前项目处于**概念验证阶段**：

1. **第一步** - 验证两个skill之间能否互相调用 ✅ 完成
2. **第二步** - 测试在不同skill中指定不同模型  🔄 进行中
3. **第三步** - 如果框架实现不完整，改进底层实现
4. **第四步** - 真实业务场景验证
